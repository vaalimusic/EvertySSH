## Terminal Emulation & Keyboard Improvements

- Full support for Function keys **F1–F12** across terminal sessions, resolving key navigation in tools like Midnight Commander (`mc` F10 quit), `htop` (F2 setup, F3/F4 search), `nano`, `less`, etc.
- Support for **Application Cursor Keys mode** (DEC Private Mode 1 / DECCKM), correctly sending VT application escape sequences (`\x1bOA`–`\x1bOD`) when requested by full-screen ncurses applications.
- Additional navigation keys: Escape (`\x1b`), Insert (`\x1b[2~`), Delete (`\x1b[3~`), Page Up (`\x1b[5~`), Page Down (`\x1b[6~`), Home (`\x1b[1~`), End (`\x1b[4~`).
- Extended ANSI terminal parser commands: CHA (`CSI G`), ECH (`CSI X`), DCH (`CSI P`), ICH (`CSI @`), DL (`CSI M`), IL (`CSI L`), VPA (`CSI d`), DECSC (`ESC 7`), DECRC (`ESC 8`), and Reverse Index (`ESC M`).
- Fixed Readline/bash history line replacement overlap during rapid Up/Down arrow navigation.
- Added standard autowrap delay behavior: characters at the right edge no longer wrap prematurely until the following character is output.
- Dynamic event loop polling: when output is pending from SSH/pty, the event loop runs unthrottled, removing visual lag and frame delays during rapid typing or scrolling.

## Built-in Update Checker

- New Update Checker card in **Settings -> About**.
- Checks the GitHub Releases API asynchronously in the background.
- Displays current version, status ("Up to date", "Checking...", or "New version available"), and provides a direct one-click button to download updates.

## Multi-platform Linux Packaging

- Official Linux x86_64 packages:
  - **Debian / Ubuntu** package: `everty-ssh_<version>_amd64.deb`
  - **Red Hat / Fedora / CentOS** package: `everty-ssh-<version>-1.x86_64.rpm`
  - **Portable archive**: `EvertySSH-linux-x64.tar.gz`
  - Standalone Linux executable: `everty-ssh`
- Linux desktop integration includes `.desktop` launcher and application icons.
- Windows packages continue to provide standalone executable `everty-ssh.exe` and portable zip `EvertySSH-windows-x64.zip`.

## UI & Visual Polish

- Server names in tab headers and sidebar gracefully truncate with ellipsis instead of overflowing.
- Improved button hover feedback and responsiveness in Settings.
