## Security and reliability

- Store SSH passwords and key passphrases in the operating system credential store, with migration from legacy plaintext configuration.
- Encrypt new backups with Argon2id and XChaCha20-Poly1305. Legacy v1 JSON backups remain importable.
- Record commands through opt-in shell integration instead of logging terminal keystrokes. Interactive password responses are not recorded.
- Save configuration atomically, detect external edits, and report load/save failures.
- Support bracketed paste and preview multiline paste before sending it to the original session.
- Queue host-key confirmations and exclude confirmation time from the network timeout.
- Bound SSH output buffering and UI processing; apply configured terminal scrollback limits.
- Fix scrollbar behavior in compressed windows and block connection shortcuts while the application is locked.

## Development

- Separate session, settings, history and dialog logic into modules.
- Add isolated regression tests and CI checks on Windows, Linux and macOS.
- Require passing checks before release packaging.

## Upgrading

Command recording is off by default. See `docs/SHELL_INTEGRATION.md` for remote Bash setup.
The startup master password locks the interface; it does not encrypt host metadata or SQLite history.
Backup encryption uses a separate password. Backups do not include private-key files, snippets or session history.
Linux requires an unlocked Secret Service provider for saved credentials. Building requires Rust 1.89 or later.

Windows downloads include the executable and a portable ZIP with documentation.
