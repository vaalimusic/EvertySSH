## Terminal Emulation & Display Architecture Overhaul

- **Persistent Dual Screen Buffers (Primary & Alternate)**:
  - Added dedicated Alternate Screen Buffer storage with full support for DEC private modes `47`, `1047`, `1048`, and `1049`.
  - Switching between primary screen and alternate screen cleanly saves and restores terminal contents and cursor positions.
  - Fixes background ghosting and residual trails when opening, viewing, editing, or closing files in Midnight Commander (`mc`), `nano`, `btop`, `htop`, etc.
  - Alt screen mode isolates scrollback, preventing alt-screen TUI apps from polluting the terminal history or scrolling away into old buffers.

- **DECSTBM Margins & Region-Bounded Scrolling**:
  - Full support for DECSTBM (`CSI top ; bottom r`) terminal scrolling regions.
  - Implemented Scroll Up (`CSI S`) and Scroll Down (`CSI T`) constrained within margins.
  - Line deletions (`DL` / `CSI M`), line insertions (`IL` / `CSI L`), linefeeds (`\n`), and reverse index (`ESC M`) now strictly respect active scrolling margins, preventing destruction of top status headers or bottom hotkey bars in full-screen utilities.

- **Modifier Combinations for Function & Navigation Keys**:
  - Full support for **Shift + F1–F12**, **Ctrl + F1–F12**, and **Alt + F1–F12** with standard xterm modifier encoding.
  - Enables essential Midnight Commander combinations such as `Shift + F5` (in-place copy) and `Shift + F6` (in-place rename).
  - Support for **Shift + Tab** (Backtab / `\x1b[Z`).
  - Modified navigation keys (Shift/Ctrl/Alt + Arrow keys, Home, End, PageUp, PageDown) now transmit standard xterm escape sequences.

- **Terminal Query & Reporting Protocol**:
  - Implemented Device Status Report (DSR / CPR `CSI 6 n` -> `\x1b[{row};{col}R` and `CSI 5 n` -> `\x1b[0n`).
  - Implemented Primary Device Attributes query (`CSI c` -> `\x1b[?6c`).
  - Terminal query responses are automatically dispatched over SSH immediately upon reception, satisfying cursor positioning handshakes in advanced TUI frameworks.

- **Cursor Position & Screen Clearing Fixes**:
  - Corrected `ED 2` (`\x1b[2J`): clears active screen contents without erroneously jumping cursor to (0, 0), fixing cursor placement upon exiting programs like `btop`.
  - Implemented `ED 3` (`\x1b[3J`): clears scrollback buffer without wiping active viewport contents.
  - Mouse wheel scrolling inside alternate screen mode forwards cursor up/down keystrokes for natural scrolling in pagers and viewers.
