# Keyboard Shortcuts & Navigation ⌨️

EvertySSH features full dual-layout keyboard tracking: all combinations work identically on **English (QWERTY)** and **Russian (ЙЦУКЕН)** layouts.

---

## 🪟 General & Window Controls

| Shortcut (EN) | Shortcut (RU) | Action | Scope |
|---|---|---|---|
| `Ctrl + N` | `Ctrl + Т` | Open "Add New Server" dialog | Global |
| `Ctrl + R` | `Ctrl + К` | Open Command Palette / History Search | Global |
| `Ctrl + T` | `Ctrl + Е` | Quick connect / Open session tab | Global |
| `Ctrl + W` | `Ctrl + Ц` | Close active terminal tab or split view | Global |
| `Ctrl + Alt + S` | `Ctrl + Alt + Ы` | Toggle horizontal Split Screen view | Global |
| `Esc` | `Esc` | Close open modal, search bar, or overlay | Global |

---

## 💻 Terminal Session Controls

| Shortcut (EN) | Shortcut (RU) | Action | Scope |
|---|---|---|---|
| `Ctrl + F` | `Ctrl + А` | Open terminal text search widget | Terminal |
| `Enter` | `Enter` | Jump to next search match | Search Widget |
| `Shift + Enter` | `Shift + Enter` | Jump to previous search match | Search Widget |
| `Ctrl + Shift + V` | `Ctrl + Shift + М` | Paste text into terminal | Terminal |
| `Shift + Insert` | `Shift + Insert` | Alternative terminal paste | Terminal |
| `Ctrl + C` | `Ctrl + С` | Copy selected text (or send SIGINT if no selection) | Terminal |
| `Page Up` / `Page Down` | `Page Up` / `Page Down` | Scroll terminal buffer up / down | Terminal |
| `Home` / `End` | `Home` / `End` | Scroll to top / bottom of scrollback | Terminal |

---

## 📝 Input Fields & Dialogs

| Shortcut (EN) | Shortcut (RU) | Action | Scope |
|---|---|---|---|
| `Tab` | `Tab` | Advance focus to next input field | Modals |
| `Shift + Tab` | `Shift + Tab` | Focus previous input field | Modals |
| `Ctrl + A` | `Ctrl + Ф` | Select all text in active field | Input Field |
| `Ctrl + C` | `Ctrl + С` | Copy selected text | Input Field |
| `Ctrl + V` | `Ctrl + М` | Paste text from clipboard | Input Field |
| `Ctrl + X` | `Ctrl + Ч` | Cut selected text | Input Field |
| `Ctrl + Left` / `Ctrl + Right` | `Ctrl + Стрелка влево/вправо` | Jump cursor by whole word | Input Field |
| `Ctrl + Backspace` | `Ctrl + Backspace` | Delete word backwards | Input Field |
| `Ctrl + Delete` | `Ctrl + Delete` | Delete word forwards | Input Field |
| `Shift + Left` / `Shift + Right` | `Shift + Стрелка влево/вправо` | Expand text selection by character | Input Field |
| `Enter` | `Enter` | Submit / Confirm dialog action | Modals |
| `Esc` | `Esc` | Cancel / Dismiss modal | Modals |
